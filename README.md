# 田野考古发掘数字化管理系统

面向考古发掘现场探方管理、地层记录、遗迹测绘、遗物登记、浮选采样与测年送检全流程的田野考古数字化管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 示例数据初始化（幂等、可回退、跨环境同一套规则）

应用挂载前会先执行 `frontend/src/data/init.ts` 的初始化流水线，本地开发（`npm run dev`）、
构建预览（`npm run preview`）、部署环境、以及浏览器里已有旧版本地存储，走的都是同一份纯前端
规则，不依赖任何环境变量或后端。

- **幂等**：每条历史总账按稳定流水号处理一次并记入 `consumed`，重复启动不会增加重复记录；
  已是最新结构且没有新总账时状态为 `unchanged`，不写任何业务数据。
- **缺归属历史记录只按关联核对，不猜测**：旧运营概览遗留的「登记总账」只有登记总量、没有模块
  归属。初始化时拿总账的关联编号与本地记录精确核对——`STRA-` 编号在「地层记录」存在才回填到
  地层，`FEAT-` 编号在「遗迹单位」存在才回填到遗迹；编号查无此号、缺少线索、疑似重复的，
  一律进入运营概览的「待归属」队列，由人工指定模块后才落账，绝不覆盖或猜测填写业务字段。
  回填记录带 `_总账流水号 / _来源` 等追溯字段。示例总账见 `frontend/src/data/ledger.ts`。
- **跨页面同口径**：运营概览不再保存独立快照，登记总量等指标一律从各业务模块的本地记录实时
  汇总；待归属记录单独成卡，不计入任何模块存量，因此运营概览、地层记录、遗迹单位三处口径一致。
- **整批事务**：先在内存里算好全部结果并校验（版本、模块、编号唯一性），再一次性落盘；任一步
  落盘失败就按快照把受管控键整体恢复到初始化前状态，不会留下半截数据。本地存储损坏或无法识别
  时保持原数据不动，切换到内存兜底继续运行。
- **可复现日志**：每次运行写入 `field-archaeology-digital:init-log`（最近 20 次，也在控制台
  打印），含输入指纹 `inputHash`、`runId`、步骤明细、回填/挂起计数、旧概览口径差异与错误信息；
  相同输入得到相同 `runId`，可凭日志复现。运营概览页底部可展开查看。
- 初始化规则验证：`cd frontend && npm run check:init`（纯 Node + esbuild，覆盖首次播种、
  重复幂等、旧存储迁移、损坏回退、落盘失败整批回退、人工归属等场景）。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `field-archaeology-digital:entries` 这一项，或调用 `resetModule(模块)`。
  初始化日志在 `field-archaeology-digital:init-log`，两个键互不影响。
